# Data Science 500 Assignment

## Book Market Analytics: Data Collection, Exploratory Data Analysis and Price Prediction

### 1. Project Overview

This project analyses book-market data collected from the Books to Scrape website. Python is used to collect, clean, explore and analyse book information, with the aim of understanding book prices and ratings and exploring price prediction using linear regression.

### 2. Project Objectives

- Collect book information using web scraping.
- Clean and prepare the collected dataset.
- Explore book prices and star ratings.
- Create visualisations to identify patterns and relationships.
- Build and evaluate a linear regression model to estimate book prices.
- Present findings and recommendations in a written report.

### 3. Tools and Technologies

- Python
- Google Colab / Jupyter Notebook
- Beautiful Soup
- Requests
- pandas
- Matplotlib
- scikit-learn

### 4. Dataset

The dataset contains information about books collected from Books to Scrape, including book titles, prices, star ratings and stock information where available.

### 5. Project Files

- **Python notebook (`.ipynb`):** Documents the data collection, cleaning, visualisations and modelling workflow.
- **CSV dataset (`.csv`):** Stores the collected or cleaned book data.
- **PDF report (`.pdf`):** Presents the methodology, analysis, model evaluation, findings and recommendations.

### 6. Analysis and Modelling

Exploratory data analysis is used to examine price distributions, star ratings and the relationship between ratings and prices. Linear regression is used to explore whether the available features can help estimate book prices. Model performance is evaluated using MAE, RMSE and R².
